## 核心修订内容

1. **彻底清除历史版本数据残留**：
   - 全篇移除 `v1` 中遗留的历史 `2.00 / 3.50 nm` 基线对照列、`旧 v2` 列、“原 8 mm 狭缝 / 前期误述 / 消除过度收紧”等版本演进赘述；
   - 以 `ASML TWINSCAN NXT:1965Ci` 为唯一独立规格主体，如实区分原厂已公开指标（单卡盘 `DCO ≤ 2.50 nm`、参考片 `MMO ≤ 4.50 nm`）与本项目工程控制口径（双卡盘 `SMO ≤ 2.50 nm` 闭环 `2.36 nm`、独立焦面 `FU ≤ 14.0 nm` 闭环 `11.48 nm`）。
2. **建立清晰正交的 `L0–L3`（预算分账）与 `T1–T4`（现场验收）双轨分级体系**：
   - 明确切分 **`T1`（部件与传感器本体）**、**`T2a`（装机机内闭环自读）**、**`T2b`（装机外部独立标尺真值）**、**`T2 联试`（跨子系统不曝光联调）**、**`T3`（整机参考片实曝放行）** 与 **`T4`（客户产品片工艺边界）**；
   - 九大核心子系统（ENC、WS、RS 及双台同步、AA、TIS、PARIS、WS-iHOPC 11 项、物镜奇像差 Z5–Z64 全 30 项、Lens-iHOPC 8 项 + K20 边界）及六大辅助子系统逐项标注 `T` 级与具体测试方法，并汇总为一页 **[T1–T4 验收放行总卡](../outputs/reports/NXT1965Ci套刻目标_SMO2.5_MMO4.5_整机L0-L3拆解与九大子系统验收规格报告_v2.md#sec-5-1)**。
3. **简洁无歧义指标命名**：
   - 彻底拆分编码器测量链与工件台稳度命名（统一采用 `ENC-WS 宽带底噪 (1 kHz)`、`ENC-WS 曝光窗底噪 (X/Y)`、`ENC-WS 过缝切头跳变`、`栅格板 7 天网格漂移` 等直白名称），明确 `ENC` 不与台体重复计账；
   - `WS / RS` 明确区分单台独立扫描（`Sync Off`）、静止停位、1000 趟微滑移与双台同步（`Sync MA / MSD`，`WS 主台 / RS 从台`），并嵌入同向单程 vs 交替往返并排示意图。
4. **直白、去重数学化的工程语言**：
   - 新增 **[第 0.2 节：现场工程师 5 分钟读懂套刻核心名词](../outputs/reports/NXT1965Ci套刻目标_SMO2.5_MMO4.5_整机L0-L3拆解与九大子系统验收规格报告_v2.md#sec-0-2)**，用大白话讲清 `1×` 与 `4×` 折算、单层与两层 `×1.41`、固定偏置 + RSS、曝光窗 `MA/MSD`、重复性/跟随误差/在位稳定性；
   - 以直白折算表与 8 维直白体检清单替代晦涩矩阵与符号堆砌，保留全量 `UP-003` 逐行明细且保证整机总账精确闭合。
