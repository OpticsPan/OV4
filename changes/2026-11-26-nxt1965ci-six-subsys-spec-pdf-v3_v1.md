## 本次 5 项专项文献核证与结构升级明细

1. **运动 iHOPC 执行主体一手文献核证（`[注 4]` 纠偏）**：
   - 经逐篇核查本地 243 篇 OV4 文献、`ME3` 手册及公开 ASML 专利库，**尚无任何一手论文或专利直接证明“因浸没头水膜流场约束而将 K4/K5/K8/K10/K11/K14/K16/K19 动态高阶项优先分配给 RS 执行”**；v2 中该表述属工程推理，本版予以剔除。
   - 改据 ASML 一手文献重新立据：`Mulkens et al.`（Ref154 Table 1 与 *JM3* 2014 [11]）将全部 11 项运动 K 参数统一标为 `Scan`（相对扫描轨迹）；`Heertjes et al.`（2020，Ref019 §V.B [8]）与 `Naaijkens`（2013，Ref225 Ch. 7 [13]）均明确指出修正动作**由 RS 与 WS 共同执行**；ASML 专利 `US 8,237,914 B2` [12] 披露动态调制双台相对扫描速度比与横向相对轨迹实现场内高阶修正。
   - 动力学复算表明即使三阶 `K14/K19` 满档（`±1.5 nm/cm³`）所需附加加速度仅约 `7.2×10⁻⁵ m/s²`（低于 WS/RS 额定推力的 `10⁻⁵`）。故表 1.4（`WRS-T2B`）取消内部双台轨迹分工限定，严格按最终 `1×` 像面相对轨迹残差判定。
2. **WS / RS 离线干态 T1 独立验证逻辑升级（新增表 1.2 `WS-T1B` 与表 2.2 `RS-T1B`）**：
   - 鉴于 WS 与 RS 各自的离线干态平台不具备双台同步功能，但运动 iHOPC 补偿能力至关重要且双台均参与执行，本版在两章均增设独立 `T1-B` 多项式轨迹跟踪能力验收表：
     - **表 1.2 `WS-T1B`（11 项，1× 晶圆侧口径，55% 幅值 / 30.25% 方差）**：单台干态注入 0/1/2/3 阶标准多项式轨迹，5.5 mm 狭缝 MA 滤波后校验拟合残差（`K1/K2 ≤ 0.077 nm`、`K4/K5 ≤ 0.044 nm/cm`、`K6 ≤ 0.052 nm/cm`、`K8/K11 ≤ 0.026 nm/cm²`、`K10 ≤ 0.033 nm/cm²`、`K14/K19 ≤ 0.017 nm/cm³`、`K16 ≤ 0.020 nm/cm³`）；
     - **表 2.2 `RS-T1B`（11 项，4× 掩模侧物理场边口径，45% 幅值 / 20.25% 方差）**：单台干态按 `L_AB,RS = 154.0 mm` 与 `22.0 mm` 掩模窗注入等效多项式轨迹，校验 4× 场边拟合残差（`K1/K2 ≤ 0.25 nm`、`K4/K5/K8/K11/K14/K19 ≤ 0.24 nm`、`K6/K10/K16 ≤ 0.0043–0.0045 μrad`）；
     - 与 T2 联调同步/标定/狭缝耦合（70% 幅值 / 49.00% 方差）实现三向 RSS 精确闭环：`√(0.55² + 0.45² + 0.70²) = 0.9975 ≤ 1.00`。
3. **`Lens-iHOPC` 拆分为量程与精度两张独立表格**：
   - **表 6.3 `T2-B`（补偿调节范围 Range 验收表，9 项）**：单列 8 项激活 K 参数（`K3/K7/K9/K12/K13/K15/K17/K18`）有效调节量程 + `8 项联合量程占用 ≤ 80% Range`。
